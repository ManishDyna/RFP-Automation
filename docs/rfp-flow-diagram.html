📥 Download RFP — what this flow does

Runs on a schedule. Bot logs into Ariba, walks every active company, downloads any new RFP Excel, matches its materials against your master list, and emails matched ones to the bidder.

1
🔐

Login & Setup Bot · Automated

Headless browser logs into Ariba and loads the list of companies to process.

▶
1.1

🔐 Launch browser + login to Ariba

Playwright opens Chromium, fills credentials, handles any 2FA challenge.

▶
async with async_playwright() as p: browser = await p.chromium.launch(headless=True) page = await browser.new_page() await page.goto(ARIBA_LOGIN_URL) await page.fill("#UserName", ARIBA_USER) await page.fill("#Password", ARIBA_PWD) await page.click("button[type='submit']")
1.2

🏢 Load enabled companies

Read company list from config / Dataverse settings — loop one by one.

▶
Why looped

Each company has its own Ariba account + RFP listing page. The bot processes them sequentially so login state is clean.

for company in ["BAHRA", "BMS", "DYNATECH"]: print(f"▶ Processing: {company}") rfps = await scrape_rfp_listing(page, company) await download_rfp_files(page, rfps, company)
2
🔍

Scrape Listing & Download Each RFP Bot · Automated

Scrape the RFP table, skip ones we've already emailed, download the rest.

▶
2.1

📋 Scrape RFP listing table

Read every visible row → Title, Link, End Date, Status.

▶
rfps = [ { "Title": "RFP_2026_Pumps", "Link": "...Doc12345", "Status": "Open", "RFP_End_Date": "5/28/2026 5:00 PM", "Event Type": "RFP" }, { "Title": "RFP_2026_Valves", "Link": "...Doc12346", "Status": "Open", ... } ]
2.2

🔎 Check Dataverse — already processed?

Query cr673_bahra_rfp_activity_log. If Email_Status = "Sent" → skip this RFP.

▶
✅ Email already sent Skip download entirely — move to next row.
❌ No record / pending Proceed to open + download (2.3).
filter: RFP_ID eq 'RFP_2026_Pumps' and Company_Name eq 'BAHRA' result: { Email_Status: "Sent" } → return "skipped"
2.3

🌐 Open RFP detail page + extract metadata

Navigate to the RFP link, scrape Owner Name + Publish Time from the page table (with one retry).

▶
await page.goto(link, wait_until="domcontentloaded") Selector tried: div.wideLabels table td → owner = "Khalid Al-Rashid" → publish_time = "5/21/2026 3:13 PM"
2.4

📥 Click "Download Content" → save Excel

Wait until button is clickable, trigger download, save under ALLRFPs/<company>/<rfp>/downloaded-rfp/.

▶
Fallback

If Playwright's expect_download times out, the bot polls the OS Downloads folder for up to 30s and grabs the latest matching file.

async with page.expect_download() as dl: await btn.click(no_wait_after=True) download = await dl.value await download.save_as( "ALLRFPs/BAHRA/RFP_2026_Pumps/downloaded-rfp/RFP_2026_Pumps.xls" )
3
💾

Store in SharePoint + Dataverse System · Storage

Mirror the file to SharePoint and write the activity row that drives every dashboard.

▶
3.1

☁️ Upload Excel to SharePoint

Pre-check via _get_item_by_path; only upload if file is missing.

▶
sp_path = "/sites/RFPs/ALLRFPs/BAHRA/RFP_2026_Pumps/downloaded-rfp/" check = graph_client._get_item_by_path(sp_path + filename) if check.status_code != 200: graph_client.upload_file_as(local_path, sp_path, filename)
3.2

🗄️ Insert activity row in Dataverse

Single row in cr673_bahra_rfp_activity_log tracks the RFP's whole lifecycle.

▶
{ RFP_ID: "RFP_2026_Pumps", Company: "BAHRA", Owner: "Khalid Al-Rashid", Publish: "5/21/2026 3:13 PM", RFP_End_Date: "5/28/2026 5:00 PM", Downloaded: "2026-05-21 16:02:11", Email_Status: "Pending" }
4
🧩

Match Materials Against Master Bot · Automated

Parse the Excel, find which line-items we actually sell, write a per-RFP matched CSV.

▶
4.1

📑 Read Excel → extract codes + qty + UoM

Open sheet "Other Content"; scan each row for 9-digit codes, Name, Description, Quantity, UoM.

▶
Row: "Centrifugal Pump - Code 100234567 - Qty 5 - UoM EA" → material_codes = re.findall(r'\d{9}', name_text) = ["100234567"] → quantity = 5 → uom = "EA"
4.2

🔍 Two-pass matching

Method 1: exact 9-digit code match. Method 2: keyword fallback when no code is found.

▶
Method 1 — Exact Code from Excel matches a row in master_material table.
Method 2 — Keyword Keywords from Name + Description overlap with master keywords.
matched ✅: 100234567 → "Centrifugal Pump 5HP" (method=exact) matched ✅: (no code) → "Stainless Valve 2in" (method=keyword) missed ❌: 999888777 → no entry in master
4.3

🚦 Any matches? → decide email

If no row matched, log "no match" and skip email. Otherwise generate CSV and proceed.

▶
✅ Has matches Write CSV → upload to SharePoint → send email (Phase 5).
❌ Zero matches Log "no match" → no email sent → end.
4.4

📊 Write per-RFP matched-materials CSV

Export matched rows + Quantity, UoM, TDS path → upload to SharePoint.

▶
File: matched_materials_RFP_2026_Pumps_20260521_160545.csv Cols: material, ExtractedMaterial, MatchMethod, Quantity, UnitOfMeasurement, TDS_file_path, RFP_End_Date, SourceFile Uploaded to: /ALLRFPs/BAHRA/RFP_2026_Pumps/matched_materials_*.csv

📧

Build an actionable HTML email with the matched-materials table; send and mark RFP as notified.

▶
5.1

✉️ Compose actionable card email

HTML email with the matched-materials table + deep link to dashboard. Bidder responds from here.

▶
Table columns

Products | Email | Results | Remarks — Name column is hidden by design.

To: bidder@bahra.com Subject: [RFP] New RFP "RFP_2026_Pumps" — 12 matched materials [ Open in Dashboard ] [ View on SharePoint ] | Products | Email | Results | Remarks | | Centrifugal Pump 5HP| Pending | ✅ | - | | Stainless Valve 2in | Pending | ✅ | - |
5.2

📤 Send + update Dataverse

After successful send → flip Email_Status to "Sent" so step 2.2 skips this RFP next run.

▶
helpers/email_helper.py → send_actionable_card(...) On success: DATAVERSE.update_row(RFP_ACTIVITY_LOG, { Email_Status: "Sent", Email_Sent_At: "2026-05-21 16:05:33" })

📤 Submit RFP — what this flow does

Triggered manually by the bidder from the dashboard. Bot reopens Ariba, navigates the bidding wizard, imports the bidder's filled Excel, attaches TDS files, and saves the response as a draft for human review.

1
👤

User Triggers Submission from Dashboard Human · Manual

Bidder prepares the filled Excel + TDS PDFs and clicks Submit. This is the only manual step.

▶
1.1

💰 Fill Excel with prices

Bidder downloads the original RFP Excel, fills the Price column for each material, saves it.

▶
Important

Sheet names and column structure must not change — Ariba rejects the import if the schema differs from what it issued.

1.2

⬆️ Upload filled Excel + TDS PDFs

Open RFP in dashboard → upload the priced Excel + one PDF per material.

▶
Where they land

Filled Excel → /ALLRFPs/<co>/<rfp>/rfp-upload-file/
TDS PDFs → /ALLRFPs/<co>/<rfp>/tds-files/

TDS filename convention

Filename must contain the material code (anywhere) so the bot auto-matches it to the right row: e.g. 100234567_pump_spec.pdf.

1.3

🚀 Click "Submit" → fires API call

Bidder picks which TDS files to attach, then clicks Submit. Dashboard POSTs to the backend.

▶
POST /api/submit-rfp { rfp_id: "RFP_2026_Pumps", company_name: "BAHRA", allowed_tds_filenames: ["100234567_pump_spec.pdf", "100445566_valve_TDS.pdf"] } → triggers rfp/submit_rfp.py → submit_rfp(...)
2
🌐

Find RFP & Open Ariba Bidding Page Bot · Automated

Match the RFP ID against scraped portal data, then open the bidding wizard in a fresh tab.

▶
2.1

🔎 Find RFP in scraped portal data

Normalise both IDs (spaces vs underscores) via rfp_ids_match, find matching row.

▶
✅ Found Proceed to open link in new tab (2.2).
❌ Not found Return error → user sees "RFP not found in scraped portal data". Flow ends.
rfp_id = "RFP_2026_Pumps" portal Title = "RFP 2026 Pumps - BAHRA" ← different format rfp_ids_match(rfp_id, portal_title) → True ✅
2.2

🪟 Open RFP link in new tab

Use window.open so the main page stays loaded — bot drives the new tab.

▶
async with main_page.context.expect_page() as new_page_info: await main_page.evaluate(f"window.open('{link}', '_blank');") new_page = await new_page_info.value await new_page.wait_for_load_state()
3
🧭

Navigate Ariba Bidding Wizard Bot · Automated

Walk through Step 2 (accept terms) and Step 3 (set currency). These gate everything downstream.

▶
3.1

📝 Wizard Step 2 — Accept agreement

Click "I intend to respond" radio + OK + Done. Uses 4 fallback strategies for finicky radio buttons.

▶
Why robust click

Ariba's radio is often intercepted by its label. safe_radio_click tries: direct → label → force → JS click.

go_to_step(page, 2) → radio #_x3fmod ← "I intend to respond" → button #_ali5ud ← OK → button #_kfai0c ← Done
3.2

💱 Wizard Step 3 — Set currency to SAR

Anchor by visible label text (not dynamic ID), pick "Saudi Riyal".

▶
currency_combo = page.locator( "tr:has-text('Select event bidding currency') [role='combobox']" ).first await currency_combo.click() → select option text = "Saudi Riyal"
4
📂

Import Filled Excel (with validation gate) Bot · Automated

Fetch the priced Excel from SharePoint, upload to Ariba, handle confirmation dialogs, abort if Ariba rejects.

▶
4.1

🖱️ Click "Select Using Excel" → "Download Content"

Reveal the Excel import controls inside the bidding console.

▶
await page.get_by_text("Select Using Excel").click() await page.wait_for_timeout(5000) await page.evaluate("window.scrollTo(0, document.body.scrollHeight * 0.2);") → button[title*='Download Content'] now available
4.2

📂 Fetch filled Excel from SharePoint

Priority 1: rfp-upload-file/ (bidder's priced file). Priority 2: downloaded-rfp/ (original).

▶
✅ Excel found Saved to TEMP → upload to Ariba.
❌ Neither folder has Excel Raise: "Please upload the filled Excel file first." Flow ends.
Priority 1: /ALLRFPs/BAHRA/RFP_2026_Pumps/rfp-upload-file/ Priority 2: /ALLRFPs/BAHRA/RFP_2026_Pumps/downloaded-rfp/ → TEMP\RFP_2026_Pumps_filled.xlsx
4.3

⬆️ Upload Excel + click Import

Attach file, wait 9s for Ariba to parse server-side, click "Import Excel Bidding".

▶
await page.locator("input[type='file']").set_input_files(upload_path) await page.wait_for_timeout(9000) await safe_click(page, "button[title*='Import Excel Bidding']")
4.4

🚦 Validation gate — Ariba portal errors?

Scan multiple error selectors. If found → screenshot the page and abort with a clear message.

▶
❌ Error visible Screenshot → raise RuntimeError → user sees what Ariba complained about + screenshot path. Flow ends.
✅ No error Proceed to confirmation dialogs (4.5).
selectors = [".portletError", ".messageError", "#PageErrorPanel .msgText", ...] if ariba_error_text: await page.screenshot(path="LOGS/ariba_excel_error_*.png", full_page=True) raise RuntimeError(f"Ariba rejected the file — {ariba_error_text}")
4.5

✅ Confirm dialogs (lots, currency, import)

Click "Use selected lots", dismiss currency change warning + import confirmation popups.

▶
await safe_click(page, "button[title*='Use selected lots']") # currency warning (checked twice with 3s gap) await safe_click(page, "#currencyChangeWarningConfirmationId button[title='OK']") # import confirmation (up to 15s wait) await dialog.get_by_role("button", name="OK").click()
5
💾

Attach TDS Files & Save as Draft Bot · Automated

Per-material TDS attach, then click Save (NOT Submit) and flip the Dataverse status to "saved_draft".

▶
5.1

📎 Attach TDS file per material code

For each row, find a PDF whose filename contains the material code → attach via "Attach a file" link.

▶
material_to_files = { "100234567": "TEMP/100234567_pump_spec.pdf", "100445566": "TEMP/100445566_valve_TDS.pdf" } # per row in bidding console: → click "More..." → click "Attach a file" → set_input_files(file) → OK
5.2

💾 Click "Save" (NOT "Submit Entire Response")

Intentionally parks the response as a draft — final submission is left to a human.

▶
By design

Bot never auto-submits final bids — prices are too sensitive. Human logs into Ariba, reviews, then clicks Submit themselves.

await safe_click(page, "button[title*='Save your response; it will not be submitted to the owner']") # NOTE: NOT button[title*='Submit Entire Response']
5.3

🗄️ Update Dataverse status → "saved_draft"

Flip Participated column so dashboard shows the RFP as drafted and ready for human review.

▶
update_rfp_participation_status( rfp_id = "RFP_2026_Pumps", status = "saved_draft", category = "submit", log_change = True ) → logs to RFP_Activity_Log change history
